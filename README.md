# Paradise Nursery Shopping Application

Paradise Nursery is an online shopping cart web application for houseplants. Users can browse unique plant categories, view plant thumbnails, details, and pricing, add plants to their shopping cart, adjust quantities dynamically, and view total cart amounts.

## Features
- **Landing Page**: Features company branding, introduction, and a "Get Started" button.
- **Product Listing**: Displays houseplants organized into multiple categories (Air Purifying, Aromatic Fragrant, and Insect Repellent Plants), each with thumbnail images, names, descriptions, and prices.
- **Dynamic Shopping Cart**: Interactive cart badge reflecting total quantity, items summary with unit price, subtotal, increment, decrement, and item deletion capabilities.
- **Responsive Design**: Designed with modern CSS and Redux Toolkit state management.
